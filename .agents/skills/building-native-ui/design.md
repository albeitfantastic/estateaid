# Design System

This document outlines the core design principles and token values for our digital products.

## Theme Overview

The current theme is configured for a **light** color mode, providing a bright and airy user experience.

## Colors

### Palette

* **Primary Color**: `#2C554E` - This deep teal serves as the brand's most distinctive color, used for primary calls to action, interactive elements, and key branding.
* **Secondary Color**: `#607D8B` - A soothing blue-grey, this color supports less prominent UI elements, chips, and secondary actions.
* **Neutral Color**: `#F4F4F2` - A very light grey, this color provides a clean base for backgrounds, surfaces, and non-chromatic elements.

## Typography

The chosen font families ensure consistency and readability across all text elements.

* **Headlines**: `manrope` - Used for all major headings, providing a modern and clear aesthetic.
* **Body Text**: `manrope` - Consistent with headlines, `manrope` is used for all body text, ensuring cohesive readability.
* **Labels**: `inter` - Employed for labels and smaller textual elements, offering clarity and accessibility.

## Shape and Spacing

### Roundedness

UI elements feature a **subtle roundedness (1)**, offering a soft yet defined appearance. Corners are gently curved, avoiding overly sharp edges or full pill shapes.

### Spacing

The design adopts **normal spacing (2)**, providing a balanced amount of whitespace around and within UI elements for good visual hierarchy and user comfort.
